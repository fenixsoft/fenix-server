# Spec: connection-view

## ADDED Requirements

### Requirement: 连接表单与服务器管理

连接视图 SHALL 提供：服务器下拉选择（来源为本地配置服务器列表）与新增表单（名称、主机、端口默认 22、用户名默认 root、密码）；「记住密码」开关 SHALL 附带明文存储风险提示文案；客户端代理地址输入（默认 `127.0.0.1:7890` 格式校验）；连接动作 SHALL 在提交后展示连接进行中状态，连接失败 SHALL 呈现可区分错误（认证失败/网络不可达/超时）。

#### Scenario: 新增服务器并连接成功

- **WHEN** 填写正确凭据提交连接且目标可达
- **THEN** 进入任务执行视图，顶栏显示用户@主机与已连接状态

#### Scenario: 认证失败错误呈现

- **WHEN** 以错误密码连接
- **THEN** 表单显示认证失败类错误提示

#### Scenario: 记住密码展示风险提示

- **WHEN** 展开"记住密码"开关区域
- **THEN** 可见明文存储风险提示文案

### Requirement: 任务清单选择

连接视图 SHALL 允许选择任务清单来源：内置默认清单或自定义 YAML 路径；所选清单的任务在连接成功后被加载。

#### Scenario: 选择清单后连接加载任务

- **WHEN** 选择清单并成功连接
- **THEN** 任务视图呈现该清单的全部分组任务
