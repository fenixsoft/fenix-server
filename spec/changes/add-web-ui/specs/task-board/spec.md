# Spec: task-board

## ADDED Requirements

### Requirement: 分组任务树与状态呈现

任务视图 SHALL 按 `group` 分组展示任务（可折叠）；每个任务 SHALL 展示复选框、名称与状态图标（待执行/执行中/成功/失败/修复中/跳过 六态图标映射）；状态变化 SHALL 实时更新。

#### Scenario: 分组与状态图标正确渲染

- **WHEN** 加载含多分组、多状态任务的清单并执行部分任务
- **THEN** 树按分组折叠展示，各任务图标与其状态一致并实时更新

### Requirement: 级联勾选与阻塞置灰

勾选任一任务 SHALL 自动勾选其全部传递依赖；任一直接依赖未处于完成态的任务 SHALL 置灰不可勾选；「全选」「清空」SHALL 遵循相同规则。

#### Scenario: 级联勾选

- **WHEN** 勾选依赖链末端的任务
- **THEN** 其全部传递依赖被自动勾选

#### Scenario: 阻塞置灰

- **WHEN** 任务 B 依赖 A 且 A 未完成
- **THEN** B 复选框置灰禁用，直至 A 完成

### Requirement: 执行控制

任务视图 SHALL 提供「执行选中任务」（队列进度条 n/N）与「停止」；失败任务 SHALL 提供三个动作：「重试」「交给 Claude 修复」「跳过」；动作 SHALL 发送对应 WebSocket 消息且按钮状态随任务状态联动（执行中不可重复执行等）。

#### Scenario: 执行选中并观察进度

- **WHEN** 勾选 3 个任务并点击执行
- **THEN** 进度条随任务完成推进至 3/3

#### Scenario: 失败任务三动作可用

- **WHEN** 某任务执行失败
- **THEN** 该任务可见「重试」「交给 Claude 修复」「跳过」三个动作

#### Scenario: 停止执行

- **WHEN** 执行中点击停止
- **THEN** 队列停止，未开始任务回到待执行态

### Requirement: 任务详情面板

选中任务时 SHALL 展示其描述、命令列表、验证命令、依赖与文件清单、当前状态。

#### Scenario: 详情与清单一致

- **WHEN** 点击某任务
- **THEN** 详情面板内容与该任务在 YAML 中的定义一致
